# VR Exploration Game

A Google VR exploration game built in Unity.  
Traverse immersive environments, discover hidden areas, and experience virtual reality in a playful exploratory adventure.

---

## 🧭 Features

- First-person VR exploration experience  
- Multiple scenes or “worlds” to roam and discover  
- Support for Google VR (Daydream, Cardboard, or VR-enabled devices)  
- Interactive objects or triggers (e.g. doors, lights, sound cues)  
- Atmospheric environments: terrain, skyboxes, lighting  

---

## 🛠 Installation & Setup

1. Clone this repository:  
   ```bash
   git clone https://github.com/DimPapaion/VR_Exploration_Game.git
   cd VR_Exploration_Game
   ```

2. Open the project in Unity (version compatible, e.g. Unity 2019.x+ or as used in the project)

2. Ensure you have Google VR SDK imported (or whatever VR plugin the project uses)

3. Set up VR support / XR settings in Unity (enable VR/AR plugin, define supported devices)

##🎮 Usage / Play - Supported Platforms

1. Use VR headset + controller to look around and move (teleport or locomotion, depending on implementation)

2. Interact with objects by pointing and triggering

3. Explore scenes at your own pace. Trigger events or scene transitions via in-game triggers

4. Google VR (Cardboard / Daydream) / Android VR builds
